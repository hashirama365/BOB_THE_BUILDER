# CG-104 — Add CSV Export for Bookings List

## Summary

Allow users to export the current bookings list as a CSV file. The export must apply the same filters currently active in the bookings list view and download the file directly to the user's browser.

## Requirements

- A new `GET /api/bookings/export` endpoint must accept the same query parameters as `GET /api/bookings` (route, status, hazmat, container_type, date_from, date_to)
- The endpoint must return a CSV response with Content-Type `text/csv` and Content-Disposition `attachment; filename="bookings-export.csv"`
- The CSV must include columns: Booking Number, Route, Container Number, Container Type, Vessel, Status, Booking Date, Consignor, Consignee, Gross Weight, Weight Unit, Hazmat
- The bookings list page (`client/src/pages/BookingsListPage.tsx`) must include an "Export CSV" button that triggers the download using the current filter state
- The export must be a completely new route file `server/src/routes/export.ts`
- No changes to the existing bookings route or any other existing file except mounting the new router in `server/src/index.ts`

## Acceptance Criteria

- Clicking Export CSV downloads a properly formatted CSV file
- Applied filters are reflected in the exported data
- Empty filter state exports all bookings
- No existing endpoint behaviour is changed

## References

- server/src/routes/bookings.ts (reference for filter query logic only)
- server/src/index.ts (mount new export router)
- client/src/pages/BookingsListPage.tsx (add Export CSV button)
